# Схемы к теории экзамена

Сюда кладутся SVG-схемы (экспорт из Excalidraw), которые подставляются в
[Exam-Theory.md](../Exam-Theory.md).

Большие SVG не получается передать через чат (обрезаются по лимиту сообщения), поэтому
файлы добавляются в репозиторий напрямую: сохраните каждый файл в эту папку **под именем
из таблицы ниже** и закоммитьте — ссылки в теории уже стоят и сразу отрисуются.

| Файл | Тема в Exam-Theory.md | Что на схеме |
|------|------------------------|--------------|
| `01-request-flow.svg` | 1. Как устроено веб-приложение | Поток клиент ↔ сервер по HTTP и внутреннее устройство ASP.NET Core: EF, Razor Pages, MVC, Web API, Auth, Router |
| `03-layers.svg` | 3. Слои приложения и модели данных | «Представление-модель-сущность»: View ← ViewModel ← Model ← Entity ← таблица в БД, мапперы между слоями (слои Views / Services / Repositories) |
| `03-components.svg` | 3. Слои приложения и модели данных | «Структура общих компонентов системы»: Entity / Model / ViewModel, репозитории, мапперы, сущности домена (Account, Student, Teacher, Admin) |

## Нужны ещё схемы под другие темы?

Например: поток авторизации (тема 7), микросервисы и gateway (тема 10). Просто сохраните
файл сюда и скажите, к какой теме он относится, — добавлю ссылку в нужную секцию.

Если удобнее свои имена файлов — тоже не проблема: положите как есть и напишите, какой
файл к какой теме, я поправлю ссылки.
