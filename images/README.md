# Схемы к теории экзамена

SVG-схемы (экспорт из Excalidraw), которые подставляются в [Exam-Theory.md](../Exam-Theory.md).
Ширина каждой выставлена пропорционально оригиналу (~15% от ширины `viewBox`), поэтому чем
крупнее/насыщеннее схема, тем больше она отображается.

| Файл | Тема | Что на схеме |
|------|------|--------------|
| `01.svg` | 4 | SQLite (встроенная библиотека, база = файл) против PostgreSQL (отдельный сервер); приложение stateless |
| `02.svg` | 4 | Связь «многие-ко-многим» (N:N:N) преподаватель × группа × дисциплина через промежуточную сущность с тремя внешними ключами |
| `17.svg` | 7 | Права ролей (админ / преподаватель / студент) и связи предметной области: студент относится к группе, преподаватель ведёт дисциплины у групп |
| `03.svg` | 14 | Git: рабочий каталог → add → commit → push → GitHub; стадии и clone |
| `04.svg` | 9 | REST API: методы GET/POST/PUT/PATCH/DELETE и способы передачи данных (query / путь / тело) |
| `05.svg` | 12 | Десктоп-приложение против веб-приложения, которое слушает порт |
| `06.svg` | 7 | Личный кабинет: вход/выход, форма авторизации, маршруты GET/POST |
| `07.svg` | 3 | Структура компонентов: Account, StudentProfile, TeacherProfile, AdminProfile, Group и поля |
| `08.svg` | 10 | Docker: образ → контейнер, runtime, Hub, локальный ПК и удалённый сервер |
| `09.svg` | 10 | Микросервисы Marketplace + NGinX (реверс-прокси) |
| `10.svg` | 1 | Структура проекта Web API (Router → Controller → Request/Response DTO) |
| `11.svg` | 1 | Структура проекта MVC (Router → Controller, Model, View) |
| `12.svg` | 3 | Представление-модель-сущность: слои Views / Services / Repositories |
| `13.svg` | 1 | Структура проекта Razor Pages (Router → Page, Model) |
| `14.svg` | 1 | Поток запроса + устройство ASP.NET Core + разбор маршрута (POST /Users/Create) |
| `15.svg` | 3 | Контроллер-сервис-репозиторий (DDD): кто за что отвечает |
| `16.svg` | 4 | Значения по умолчанию и генерация ID (БД vs приложение), время в UTC |

Чтобы заменить схему — перезапишите соответствующий `NN.svg` своим экспортом (имя и ссылка
уже на месте). Размер при необходимости меняется в атрибуте `width` у `<img>` в Exam-Theory.md.
